# 監考查詢系統

靜態 GitHub Pages 頁面：老師以編號／姓名 + 日期查詢監考職務。

## 支援的 Excel 格式

1. **官方總表**（自動偵測）：解析 `TEACHERS P.1`（HALL／SAR／課室）、`TEACHERS P.2`（S6 特別室），以及結構相同的 `S1 - 5 1st Term TEST` 類工作表。`By Teachers code` 只作姓名對照，不用作職務來源。
2. **平面表**（後備）：工作表 `每個老師監考表`，欄位含 監考老師／日期／到場／結束／地點／科目／級號／班/組別／崗位。

請以「選取 Excel 檔案」上傳學校官方總表；勿把大型總表 commit 進本 repo。伺服器上的 `exam.xlsx` 仍會自動載入作為平面表示例。

## 本機驗證

1. 開啟 GitHub Pages 或本地靜態伺服器載入 `index.html`
2. 上傳 `2627_監考總表_v1.xlsx`（官方總表）→ 狀態應顯示「官方總表」
3. 選老師 `218`、日期 `2025-11-03` → 應見課室 301／S3 GEOG
4. 選老師 `233`、日期 `2025-11-03` → 應見 HALL 兩節 CHI
5. 再開啟／上傳平面 `exam.xlsx` → 狀態「平面表」；老師 218、日期 `2026-06-05`
