# 監考查詢系統

靜態 GitHub Pages 頁面：老師以編號／姓名 + 日期查詢監考職務。

## 支援的 Excel 格式

1. **官方總表**（自動偵測）：解析 `TEACHERS P.1`（HALL／SAR／課室）、`TEACHERS P.2`（S6 特別室），以及結構相同的 `S1 - 5 1st Term TEST` 類工作表。`By Teachers code` 與（若有）`教師名單` 只作姓名對照，不用作職務來源。
2. **平面表**（優先，若工作簿內含 `每個老師監考表`）：欄位含 監考老師／日期／到場／結束／地點／科目／級號／班/組別／崗位／來源工作表。

請以「選取 Excel 檔案」上傳學校官方總表或查詢用平面表；勿把大型總表 commit 進本 repo。可選「上載教師名單」合併姓名對照。伺服器上的 `exam.xlsx` 仍會自動載入作為平面表示例。

## 考期／來源

若同一檔案同時含 2025（如 `TEACHERS P.1`）與 2026（如 `S1 - 5 1st Term TEST`）職務，介面「考期／來源」預設為**最新年份**，避免混查。選「全部」才會同時顯示各考期。每張結果卡會標示來源工作表。

## 本機驗證

1. 開啟 GitHub Pages 或本地靜態伺服器載入 `index.html`
2. 上傳 `2627_監考總表_v1.xlsx`（官方總表）→ 狀態應顯示「官方總表」
3. 考期選 **2025**、老師 `218`、日期 `2025-11-03` → 課室 **301**／**S3 GEOG**／**11:00-11:45**（不可為 Support Time 10:30）
4. 老師 `233`、日期 `2025-11-03` → HALL 兩節 CHI
5. 上傳平面 `2627…查詢用_v2.xlsx` → 狀態「平面表」；同上金標列應一致

## 已知限制

- 合併儲存格／多行科目以 SheetJS 展開後字串解析，極複雜版面可能需微調
- ST1／校本問卷等特殊崗位以字串規則辨識；無老師編號的問卷格不會產生職務
- `By Teachers code` 職務欄常有 `#REF!`，僅作姓名；建議另上載 `教師名單`
